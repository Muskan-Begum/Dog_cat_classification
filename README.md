# 🐶🐱 Dog and Cat Image Classifier

A deep learning project built using **TensorFlow**, **Keras**, and **OpenCV** to classify images of **dogs and cats**. This model can accept images either from raw files or directly through **camera input**.

---

## 📌 Project Features

- 📷 Accepts both **uploaded images** and **camera-captured input**
- 🤖 Built using **Convolutional Neural Networks (CNNs)**
- 🧠 Utilizes **TensorFlow** and **Keras** for model design and training
- 🎯 Achieves accurate classification between **cats** and **dogs**
